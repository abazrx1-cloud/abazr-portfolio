# ABAZR — مطوّر ويب واختصاصي ذكاء اصطناعي

موقع شخصي احترافي لأبازر ميرغني، مطوّر ويب مستقل واختصاصي ذكاء اصطناعي من بورتسودان، السودان.

> يحوّل ABAZR الأفكار الطموحة إلى تجارب رقمية سريعة، واضحة، وقابلة للنمو.

## الروابط

- **الموقع المنشور على GitHub Pages:** https://abazrx1-cloud.github.io/abazr-portfolio/
- **مشروع Nile Market:** https://nilemarket.online
- **البريد الإلكتروني:** hello@abazr.dev

## عن المشروع

يعرض هذا الموقع الخدمات والخبرات والمشاريع في مجالات تطوير الويب، التجارة الإلكترونية، تطبيقات الويب، ودمج الذكاء الاصطناعي. صُممت الواجهة بالعربية مع دعم اتجاه الكتابة من اليمين إلى اليسار، وتعمل على شاشات الهاتف والكمبيوتر.

## التقنيات

| المجال | التقنية |
|---|---|
| الواجهة | React 19 وTypeScript |
| البناء | Vite |
| التنسيق | Tailwind CSS 4 وCSS مخصص |
| الخطوط | IBM Plex Sans Arabic وNoto Serif Arabic وManrope |
| الأيقونات | Lucide React |
| النشر | GitHub Pages عبر GitHub Actions |

## التشغيل محليًا

يتطلب المشروع Node.js وpnpm. بعد تنزيل المستودع، نفّذ:

```bash
pnpm install
pnpm run dev
```

لإنشاء نسخة الإنتاج والتحقق من المشروع:

```bash
pnpm run build
pnpm run check
```

## النشر

يتم النشر تلقائيًا عند رفع التغييرات إلى فرع `main` من خلال سير العمل الموجود في:

```text
.github/workflows/deploy-pages.yml
```

تستضيف GitHub Pages نسخة الموقع الثابتة، بينما تبقى ملفات المشروع ومصدره داخل هذا المستودع.

## الهوية البصرية

تعتمد الواجهة على اتجاه **Coastal Editorial Tech**: حبر داكن، رملي هادئ، ومرجاني واضح، مع إيقاع تحريري واسع وتخطيط متجاوب. تم تطوير المشروع بمساعدة أدوات الذكاء الاصطناعي مع إشراف بشري على المحتوى والهوية والتجربة النهائية.

## الترخيص

هذا المستودع مخصص لعرض مشروع ABAZR الشخصي. لا يُعاد استخدام الهوية البصرية أو المحتوى أو الأصول المرئية دون إذن صاحب المشروع.

